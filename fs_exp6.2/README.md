## FS Experiment 6.2

This folder contains a React application (inside the nested `fs_exp6.2` directory) created with Create React App.

### Project structure

- `fs_exp6.2/` – root experiment folder (this README)
- `fs_exp6.2/fs_exp6.2/` – actual React app with its own `package.json` and default CRA `README.md`

### How to run the React app

1. Open a terminal in:

   ```bash
   cd fs_exp6.2/fs_exp6.2
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open `http://localhost:3000` in your browser.
